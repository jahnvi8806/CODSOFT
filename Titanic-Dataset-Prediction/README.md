# Titanic Survival Prediction 

## Project Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning algorithms.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Logistic Regression
- Random Forest
- Gradient Boosting

## Best Model
Tuned Random Forest Classifier

## Final Results
- Accuracy: 79.89%
- ROC-AUC Score: 0.8362

## Features Used
- Passenger Class
- Gender
- Age
- Fare
- Family Size
- Embarkation Port
- Cabin Availability

## Output Files
- eda_plots.png
- model_evaluation.png
- model_comparison.png

## Run This Project

```bash
pip install -r requirements.txt
python titanic_prediction.py
```
