# Sales Prediction Dashboard

A machine learning dashboard built using Streamlit and Scikit-Learn for predicting sales based on advertising spend.

## Features

- Exploratory Data Analysis
- Linear Regression Model
- Random Forest Regressor
- Sales Prediction
- Feature Importance Analysis
- Download Filtered Dataset

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
